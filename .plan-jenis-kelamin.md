# Plan: Tambah Field `jenis_kelamin` (data profil + filter, BUKAN perhitungan CBF)

## Keputusan
- Opsi: **Laki-laki / Perempuan** (disimpan enum('L','P') di DB — singkat, label panjang di UI)
- Read-only di halaman profil (konsisten dengan fakultas/prodi/semester/angkatan)
- Tidak ikut perhitungan CBF — hanya data + filter post-Top-N

## Perubahan File

### 1. Migration baru — `database/migrations/2025_01_01_000008_add_jenis_kelamin_to_users_table.php`
```php
Schema::table('users', function (Blueprint $table) {
    $table->enum('jenis_kelamin', ['L', 'P'])->nullable()->after('nama');
});
```
- `nullable()` agar user lama tidak error
- `after('nama')` posisi rapi setelah nama

### 2. `app/Models/User.php` — tambah ke `$fillable`
```php
'jenis_kelamin',  // setelah 'nama'
```

- `store()`: tambah validasi `'jenis_kelamin' => ['required', 'in:L,P']`
- `User::create([...])`: tambah `'jenis_kelamin' => $validated['jenis_kelamin']`

### 4. `resources/views/auth/register.blade.php`

### 5. `app/Http/Controllers/RekomendasiController.php` — `index()`

### 6. `app/Services/ContentBasedFilteringService.php` — `getTopN()`
- Tambah filter post-Top-N (sama pattern dengan fakultas/prodi):
```php

    $results = $results->filter(fn ($score) =>
        $score->kandidat && $score->kandidat->jenis_kelamin === $filter['jenis_kelamin']
    );
}
```
- Update `$poolMultiplier` agar juga diperluas saat filter jenis_kelamin aktif:
```php
$poolMultiplier = (! empty($filter['fakultas']) || ! empty($filter['prodi']) || ! empty($filter['jenis_kelamin'])) ? 10 : 5;
```
